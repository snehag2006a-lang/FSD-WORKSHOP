# 🚀 Full Stack Development Workshop

Welcome to my **Full Stack Development Workshop** repository! This repository contains the practice programs and learning exercises I completed while exploring frontend development, backend development, and database concepts.

## 📚 About This Repository

The purpose of this repository is to document my learning journey and strengthen my understanding of web development through hands-on practice.

## 🛠️ Technologies & Concepts

### Frontend Development
- **HTML5** – Page structure and web elements
- **CSS3** – Styling, layouts, and responsive design basics
- **JavaScript** – Programming fundamentals and event handling
- **React.js** – Components, JSX, props, state management, forms, and conditional rendering

### Backend Development
- **Node.js** – JavaScript runtime environment
- **Express.js** – Server setup, routing, and middleware

### Database
- **MongoDB** – NoSQL database fundamentals and data organization

## 📂 Repository Structure

- `my-app/` – React practice programs and UI exercises
- `backend/` – Backend practice files and server implementation
- `webpages/` – HTML and CSS practice pages
- `.js` files – JavaScript exercises and programming concepts
- `.txt` files – Supporting files used for practice

*Note: Individual files demonstrate different practice exercises and may not form one complete application.*

## 🎯 Key Learning Outcomes

- Understanding React components and component-based UI development

- Improving programming skills through hands-on exercises

## ▶️ Running the React Practice App

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository:
   ```bash
   git clone https://github.com/snehag2006a-lang/FSD-WORKSHOP.git
   ```
3. Navigate to the React project:
   ```bash
   cd FSD-WORKSHOP/my-app
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```

Open the local URL displayed in your terminal.
